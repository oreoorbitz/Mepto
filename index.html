📝 Example Code

Open browser console (F12) and try:

// Select elements
$('h1').text('Hello Mepto!');

// Add classes
$('#test-box').addClass('highlight');

// Chain methods
$('.demo-box').css('border-color', '#667eea').fadeIn();

// Event handling
$('button').on('click', function() {
  console.log('Clicked!', $(this).text());
});

// AJAX (if you have a server)
$.get('/api/data', function(data) {
  console.log(data);
});
